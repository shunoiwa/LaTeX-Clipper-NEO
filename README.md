# LaTeX-Clipper-NEO
.NET 9 と TeXさえ環境に入っていれば使えるLaTeX画像生成ソフト！追加で、mhchem, physics が必要です。
自分用のAI製ツールなので、開発力の参考にはなりません...

## 必要なもの
- .NET 9
- TeX Live
  - 基本セット
  - mhchem
  - physics

## できること
LaTeX数式を入力すると、プレビューが見れます。
コマンドや環境名の入力補助機能があり、Tab / Shift+Tab で選択、Enterで確定・自動入力します。
右下のボタンでpng / epsをクリップボードにコピーできます。powerpointとかで使うなら解像度を高くしてPNGを使ってね！
